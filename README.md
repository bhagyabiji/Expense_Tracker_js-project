# Expense Tracker 

A web application built using HTML, CSS, and JavaScript to manage daily income and expenses.

The application allows users to add transactions, track their income and expenses, calculate their remaining balance, and store transaction data in the browser using Local Storage.

##  Features

- Add income and expense transactions.
- Enter transaction descriptions and amounts.
- Select transaction type and category.
- View total income.
- View total expenses.
- Calculate remaining balance automatically.
- Delete transactions.
- Save transaction data using Local Storage.
- Data remains available after refreshing the browser.

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

##  How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your default web browser.



##  How It Works

1. Enter a transaction description.
2. Enter the amount.
3. Select Income or Expense.
4. Choose a category.
5. Click **Add Transaction**.
6. View the updated balance and transaction history.
7. Delete a transaction whenever required.
